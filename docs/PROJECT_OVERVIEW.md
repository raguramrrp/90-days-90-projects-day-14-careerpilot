# CareerPilot — Project Overview

## 1. Problem Statement
Job hunting and internship preparation for students and early-career software engineers are typically fragmented across spreadsheets, browser bookmarks, WhatsApp/Telegram messages, notes apps, and calendar reminders. Important application deadlines pass unnoticed, recruiter follow-ups are neglected, customized resume versions get mixed up, and interview preparation lacks a structured feedback loop.

## 2. Solution: CareerPilot
**CareerPilot** is an intelligent, centralized personal career and job application management CRM. It transforms chaotic job search tracking into an organized daily operating system.

### Core Capabilities:
1. **Opportunity Management:** Save opportunities prior to applying, record salary bands, qualification criteria, and detect potential duplicate postings.
2. **10-Stage Pipeline Tracking:** Manage applications through defined stages (*Saved, Interested, Applied, Assessment, Tech Interview, HR Interview, Offer Received, Accepted, Rejected, Withdrawn*) with automatic, non-destructive audit history logging.
3. **Daily Career Operating System ("My Day"):** A focused view displaying overdue follow-ups, upcoming interviews within 48 hours, today's habit tasks, and real-time weekly target progress bars.
4. **Interview Preparation & Retrospective Archive:** Track multiple interview rounds per company with interactive prep checklists, questions asked, algorithms used, and self-evaluation notes.
5. **Resume & Document Manager:** Store multiple resume versions categorized by target job profile (Software Engineer, AI/Data Science, etc.), and maintain an audit of which resume version was submitted to which employer.
6. **Career Intelligence & Analytics:** Transparent, rule-based recommendation engine coupled with 10 database-calculated visual charts and filterable Excel/CSV data exports.
