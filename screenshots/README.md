# CareerPilot UI Screenshots & Visual Previews

This directory contains visual previews and recommended screenshot captures of CareerPilot in action.

## Recommended Portfolio Capture Sequence:

1. `01_command_center_overview.png`:
   - Route: `/`
   - Content: The executive command center displaying candidate welcome greeting, 4 KPI cards (Opportunities, Active Applications, Upcoming Interviews, Conversion Rate), dual Chart.js pipeline distribution & activity trend charts, approaching deadlines, today's tasks, and rule-based career recommendations.

2. `02_my_day_daily_planner.png`:
   - Route: `/my-day/`
   - Content: Focused daily dashboard displaying the weekly application goal progress bar, overdue tasks, today's priority task list with real-time toggle checkboxes, immediate 48-hour interview alerts, and overdue recruiter follow-up notices.

3. `03_pipeline_kanban_board.png`:
   - Route: `/applications/pipeline/`
   - Content: Full 10-stage horizontal pipeline Kanban board (*Saved, Interested, Applied, Assessment, Tech Interview, HR Interview, Offer Received, Accepted, Rejected, Withdrawn*) with application cards and drag/drop capability.

4. `04_application_detail_timeline.png`:
   - Route: `/applications/1/`
   - Content: Detailed application view showing candidate specifics, submitted resume version badge, linked interview rounds, recruiter contact information, and the automatic chronological stage transition history timeline.

5. `05_interview_prep_checklist.png`:
   - Route: `/interviews/1/`
   - Content: Interview management view showing interview schedule logistics, meeting URL, interactive 8-step preparation checklist with dynamic percentage bar, target topics, and debrief notes.

6. `06_career_analytics_10_charts.png`:
   - Route: `/analytics/`
   - Content: Complete analytics dashboard showing 10 charts (monthly submissions, stage distribution, job category, work mode, discovery sources, interview outcomes, activity trends, offer conversion funnel, and pipeline health ratio) alongside strategy observations.

7. `07_calendar_schedule_view.png`:
   - Route: `/calendar/`
   - Content: Color-coded calendar showing application deadlines, interview rounds, recruiter follow-ups, and career tasks across monthly, weekly, and daily agenda views.

8. `08_dark_mode_workspace.png`:
   - Route: `/` (with Dark theme toggled)
   - Content: Demonstrates the deep charcoal/slate dark theme (`#0F172A` / `#1E293B`) maintaining high contrast and accessibility.

## How to Capture:
1. Start the server: `run.bat`
2. Open `http://127.0.0.1:8000/` in your browser.
3. Log in with `demo_user` / `DemoPassword123!`.
4. Capture using Windows Snipping Tool (`Win + Shift + S`) and save into this directory.
