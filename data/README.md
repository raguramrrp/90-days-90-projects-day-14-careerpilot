# CareerPilot — Sample Data & Demonstration Fixtures

This directory documents the synthetic data structures generated by the built-in management command:

```powershell
python manage.py load_sample_data
```

## Included Demonstration Entities:
1. **Candidate Profile (`demo_user`):**
   - Final-year B.Tech student targeting Software Engineer & AI roles.
   - Customized career preferences, default 7-day follow-up interval.
2. **Companies & Opportunities:**
   - 7 realistic tech employers (Razorpay, Zoho, Atlassian, Google India, Microsoft IDC, Swiggy, CRED).
   - Across full-time and internship classifications.
3. **Applications:**
   - Populated across stages (*Technical Interview, Assessment, Offer Received, Rejected, Saved*).
   - Real status change histories with timestamped transition records.
4. **Interviews:**
   - Multi-round interviews with seeded 8-step preparation checklists.
   - Past interview debriefs with actual coding questions and algorithms used.
5. **Reminders & Tasks:**
   - Upcoming reminders, overdue recruiter follow-up dates, and habit planner tasks.
6. **Career Goals:**
   - Weekly application targets with real-time calculated progress.
